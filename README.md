# NailongRedact

一款离线本地运行的 iOS 聊天截图隐私打码工具，适配 iPhone 液态玻璃界面与快捷指令。

## 核心功能

- **微信 / QQ 奶龙化**：自动识别聊天头像（适配方形与圆形）与昵称，替换为最多 10 种不同基底色的奶龙头像变体及随机情绪颜色昵称。
- **隐私脱敏**：自动识别并打码手机号、身份证号、银行卡号、微信号、邮箱及 `@提及`。
- **指哪打哪马赛克**：支持划选局部文本或自由框选区域打码，支持回退、前进与长按对比原图。
- **人物优先级**：支持调整 10 个奶龙头像的分配优先级与自定义昵称，导出自动抹除 EXIF 信息。
- **快捷指令**：内置「奶龙打码并存入相册」动作，处理后直接保存到系统相册。
